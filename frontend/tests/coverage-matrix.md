## Примечания

- Acceptance-тесты используют реальную тестовую БД, подключённую к backend.
- Исторические данные испытаний, включая заявки, акты и журнал аудита, после выполнения тестов не удаляются.
- Для повторяемых испытаний рекомендуется использовать отдельную тестовую БД или очищать данные перед прогоном.
- Переход к парному акту и визуальная пригодность печатных форм относятся к UI/ручной проверке в ПМИ.
- Для PDF backend использует LibreOffice, если он установлен на сервере; при отсутствии LibreOffice применяется fallback-формирование PDF из HTML.
